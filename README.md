# MEXC Mobile Scalper

تطبيق Kivy لماسح وتداول MEXC Spot.

## المزايا الحالية

- فحص أفضل **200 زوج USDT** حسب `quoteVolume`.
- فريمات الاتجاه: 5m / 15m / 60m.
- EMA 9 / EMA 21 / EMA 200.
- VWAP.
- فلتر حجم مرتفع.
- شراء Market.
- TP / SL.
- إغلاق يدوي.
- حفظ الصفقة المفتوحة والسجل باستخدام SQLite.
- استعادة الصفقة بعد إعادة تشغيل التطبيق.

## التشغيل

```bash
python -m pip install -r requirements.txt
python main.py
```

## تحذير أمني مهم

لا ترفع ملف `bot_data.db` إلى GitHub لأنه قد يحتوي على API Key وSecret Key.

أنشئ API Key في MEXC بصلاحيات التداول اللازمة فقط، ويفضل عدم تفعيل السحب.

## ملاحظة

هذه النسخة تحافظ على منطق الاستراتيجية الأصلي، والتعديل الأساسي هو رفع عدد العملات المفحوصة من 100 إلى 200.
